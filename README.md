# SmartVerse

Solar & Inverter Load Calculator Mobile App.

SmartVerse is a mobile application designed to help Nigerian homeowners and small businesses determine the right inverter, battery, and solar panel capacity based on the appliances they use.

## Project Overview

The application allows users to calculate their power requirements based on their appliances and use those calculations to determine suitable solar and inverter system capacities.

The project is being developed to make solar power planning easier and more accessible for users in Nigeria.

## Tech Stack

* Flutter
* Dart

## Getting Started

### Prerequisites

Make sure you have Flutter installed on your machine.

You can check your Flutter installation with:

```bash
flutter doctor
```

### Installation

Clone the repository:

```bash
git clone https://github.com/Williams-777/smartversemobile.git
```

Navigate into the project:

```bash
cd smartversemobile
```

Install the dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
