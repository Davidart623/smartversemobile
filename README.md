# SmartVerse

SmartVerse is a mobile application for calculating solar and inverter load requirements.

The app helps Nigerian homeowners and small businesses determine the appropriate inverter, battery, and solar panel capacity based on the appliances they use.

## Project Duration

17th August – 17th September 2026

## Getting Started

### Prerequisites

* Flutter
* Dart
* Android Studio or VS Code

### Installation

Clone the repository:

```bash
git clone https://github.com/grazac-academy/smartversemobile.git
```

Navigate to the project directory:

```bash
cd smartversemobile
```

Install the project dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
